# NovaMart App Troubleshooting

## App crashes on launch

Force-close the app and reopen it. If it still crashes, check for an update in your app
store — most launch crashes are fixed by moving to the current version.

## Android version 3.2.0 crash on checkout

There is a known crash on **Android app version 3.2.0** when opening the basket. The
workaround is to update to **3.2.1 or later**, which contains the fix. Customers who cannot
update can place the order from the NovaMart website in a mobile browser.

Report the app version and the device when this happens, so the case carries the detail an
engineer needs.

## Cannot sign in

Check that the email address is the one used to create the account. Use **Forgot password**
to reset a password. Sign-in problems that survive a password reset need a support agent —
account access is never resolved in this chat.

## Order missing from order history

Orders placed as a guest do not appear in account order history. An order id from the
confirmation email can still be looked up here.

## Push notifications not arriving

Check notification permissions for NovaMart in the device settings, then check the
notification preferences in the app's account section. Both must be on.
